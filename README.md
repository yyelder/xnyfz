
## 省常技电气仿真

常用照明电路与电力拖动电路的**交互式仿真教学平台**。学生可在原理图上直接操作断路器、开关、按钮，
实时观察通断电效果（导线带电变色、灯点亮、电机转动、接触器吸合、时间继电器倒计时、短路保护动作等）。

技术栈：**Node.js + Vue 3 + Electron**（目录组织对齐 [electron-egg](https://github.com/dromara/electron-egg) 的 controller / service / frontend 分层约定）。


---

## 快速开始

```bash
npm install

# 网页模式（浏览器直接打开，资源包内置）
npm run dev:web        # http://localhost:5173

# 桌面模式（Electron + Vite 热更新）
npm run dev

# 生产构建
npm run build:web      # 生成 frontend/dist
npm start              # Electron 加载 frontend/dist

# 引擎验收测试（66 项断言）
npm run test:engine

# 查看桌面端资源库内容
npm run seed:dump
```

> 在某些终端（如 WorkBuddy 内置终端）中启动 Electron 需先移除
> `ELECTRON_RUN_AS_NODE` 环境变量：`env -u ELECTRON_RUN_AS_NODE npm start`。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 10 个内置课程 | 照明：单控、双控（两地控制）、荧光灯、照明配电箱（漏电保护）、**一灯一控一插座**；拖动：点动、自锁（起保停）、正反转（接触器联锁）、星—三角降压启动、**电动机两地控制** |

| 元件状态面板 | 线圈得电、触点位置、电机转向/接法/绕组电压、热继电器与断路器状态 |
| 故障注入 | 短路（保护自动脱扣切除）、热继电器过载 |
| 运行日志 | 每一次得电/失电/跳闸/换向事件实时记录，可用于实训报告 |
| 原理/步骤/考核 | 每课程内置原理说明、实训步骤、考核要点，可在资源包中编辑 |
| 交叉线跳线 | 原理图交叉处自动绘制半圆跳线弧，符合制图规范、避免歧义 |

## 资源数据库（扩展与自定义的核心）

**所有电气资源都是数据，不是代码。** 桌面端首次启动时，`resources/packs` 会被导入到用户数据目录的
独立资源库（`%APPDATA%/scj-elec-sim/scj-resource-db.json`），此后课程与元件的增删改都不需要动代码：

1. **新增元件**：在 `device-types.json` 中追加一个条目（引脚坐标 + 导电策略 + 符号名），
   若是全新符号需在 `shared/render/symbols.js` 补一个绘制函数（约 10 行）。
2. **新增课程**：复制 `circuits/` 下任一 JSON 修改（布局坐标 + 网络接线 + 教学文案），
   重新启动即自动按 `seedVersion` 导入；用户自建电路始终保留。
3. **调整参数**：时间继电器延时（`props.delay`）、断路器初始状态、故障注入点都是课程数据字段。
4. **切换数据库驱动**：`electron/service/resource-db.js` 已抽象出
   `init / getBundle / saveCircuit / deleteCircuit / reset` 接口，
   如需 SQLite，只需按同一接口实现驱动（如 better-sqlite3）并替换构造处。

## 仿真引擎原理（拓扑逻辑仿真）

1. **网络归并**：导线与闭合触点通过并查集合并为等电位节点；负载（线圈/灯/绕组）不参与合并；
2. **得电判定**：负载两端落在「带相电位」与「中性线/异相」节点上即得电；
3. **联动迭代**：线圈得电 → 同组触点变位 → 重新归并 → 迭代至收敛（自锁、互锁由此自然涌现，振荡电路会被检测并标记）；
4. **电机判定**：三相互备判缺相，相序排列判正反转，六端子电机按末端归并判 Y/Δ 接法并计算绕组电压；
5. **保护动作**：检测 L-N 短路与相间短路，自动使闭合的断路器脱扣切除故障。

`npm run test:engine` 用 10 个课程的关键操作序列 + 网络标号专项用例做 88 项断言（点动、自锁、联锁、Y-Δ 切换、两地控制、短路保护、标号等电位……）。

## 搭建模式操作速查

| 操作 | 方式 |
| --- | --- |
| 放置元件 | 右侧元件库点选 → 画布上点击放置（10px 网格吸附） |
| 移动元件 | 直接按住拖动（选择工具下），坐标实时吸附网格 |
| 旋转 / 删除 | 选中后按 `R` 旋转 90°，`Delete` 删除 |
| 手工走线 | 切到「走线」工具 → 点起点引脚 → 点击画布添加拐点 → 点终点引脚完成；Esc 取消 |
| 网络标号 | 点击画布上的导线（或右侧「网络标号」页签选网络）→ 输入标号回车；同名标号等电位 |
| 接线检查 | 「接线检查」页签：统计未连接引脚与悬空网络 |
| 编辑副本 | 课程模式下点「编辑副本」，在现成电路上改完另存为「我的电路」 |
