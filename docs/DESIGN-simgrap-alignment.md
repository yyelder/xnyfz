# 省常技电气仿真 · 对齐「科玩电工仿真」（simgrap.com）产品设计方案

> 调研日期：2026-11-19（真实浏览器实测 simgrap.com 全部主要页面）
> 结论先行：竞品是一个「**拟实物端子接线 + 双视图（实物/原理图）+ 社区作品广场**」的电工实训平台。
> 本方案在保留现有 scj-elec-sim 仿真内核与资源数据库架构的前提下，将产品形态完整对齐。
> **按用户要求：不含 VIP / 会员 / 付费相关功能。**

**接线交互（官方教程原文）**：「点击元器件中的端子开始接线；需要转弯再点击一下，点击元器件端子完成连线。」——即 **端子 → 拐点（可多次） → 端子** 的手工走线模式。

### 1.3 仿真表现

- 元件为**拟实物渲染**（与真实电工实训台器件外观一致），端子带端子号：接触器 `1L1/3L2/5L3/2T1/4T2/6T3/A1/A2/13NO/14NO`，按钮常开/常闭等
- 导线按相别配色：L1 黄、L2 绿、L3 红、N 蓝、PE 黄绿、控制线红/黑
- 进线端子排：`L1 L2 L3 N PE`
- 运行态：合闸 → 接触器吸合（按钮变「吸合」红态）→ 数显时间继电器倒计时 → 电机旋转动画 → 指示灯/灯泡点亮
- 双视图：同一作品提供实物接线视图 + 原理图视图（详情页两个区块）

### 1.4 不做的功能（用户指定）

- VIP / 会员 / 免费会员招募、多端付费墙 —— 全部去掉
- 「下载APP / 鸿蒙 / 苹果」多端引导 —— 桌面端优先，网页版按需

## 三、总体架构（保留现有骨架）

```
scj-elec-sim/
├─ shared/
│  ├─ engine/          # 拓扑仿真内核（现有，扩展端子级网络+动画状态）
│  ├─ render/
│  │  ├─ schematic/    # 原理图渲染（现有）
│  │  └─ physical/     # ★新增：拟实物渲染器（元件外观 + 端子 + 导线配色 + 动画）
│  └─ curriculum/      # 练习校验逻辑（目标电路对照、完成率）
├─ resources/packs/    # 独立资源数据库（继续作为唯一数据源）
│  ├─ device-types.json        # 原理图元件定义（现有）
│  ├─ physical-devices/        # ★新增：拟物元件定义（SVG 外观 + 端子表），一元件一文件
│  ├─ circuits/                # 课程/作品（现有 10 课 + 新增练习课题）
│  └─ practice/                # ★新增：常用电路练习包（难度/目标电路/校验规则/完成率）
├─ electron/           # 主进程 controller → service → resource-db（现有分层不变）
└─ frontend/           # Vue3 页面化改造：首页/精选/广场/电工必备/工作台/编辑器/详情
```

**关键决策**（一句话理由）：
1. **仿真内核复用**：现有拓扑引擎已验证 88 项断言，端子级网络可由「端子→导线段」关系推导，不必推倒重来。
2. **拟物渲染用参数化 SVG**：每个元件一个定义文件（外观图层 + 端子锚点 + 动画槽位），便于教师/用户自定义扩展——延续「资源即数据」理念。
3. **作品数据 JSON 进 resource-db**：桌面端存 `%APPDATA%` 资源库，云端共享为可选层，不上云也能完整使用。
4. **双视图同源数据**：电路数据增加 `views` 字段，原理图可由实物接线自动推导布局（一期先手绘模板，二期自动布局）。

### 电路数据 schema v2（草案）

```jsonc
{
  "id": "wd_xxx", "title": "星三角降压启动电路", "category": "industrial",  // industrial|home|exam
  "views": { "physical": {...}, "schematic": "auto|template-id" },
  "devices": [
    { "id": "KM1", "typeId": "ac-contactor-3p", "x": 820, "y": 460, "rotation": 0,
      "label": "KM1", "ref": "CJX2-2510" }
  ],
  "wires": [
    { "id": "w1", "color": "L1",            // L1|L2|L3|N|PE|ctrl-red|ctrl-black|custom
      "points": [[x,y],[x,y],[x,y]],        // 正交折线，首尾吸附端子
      "ends": ["QF1:2", "KM1:1L1"] }        // device:terminal
  ],
  "terminalTable": { "QF1": ["1","3","5","2","4","6"] }  // 运行期由元件定义合并
}
```

### 仿真运行映射

- 端子网络 = 导线段连通 + 同名端子标号（保留现有网络标号等电位机制）
- 线圈得电 → 触点动作（引擎现有迭代收敛）→ 渲染动画槽位：`coil-on`（吸合）、`motor-run`（旋转帧）、`lamp-on`（发光）、`timer-countdown`（数显倒计时）
- 新增端子动画：端子带电高亮、导线通电流动光效（CSS/SVG animation）

## 四、实施路线图

**一期 · 核心可交付（拟物编辑器 + 仿真运行）**
1. `physical-devices` 首批 40 种元件定义（覆盖现有 10 课所需 + 高频元件：空开、熔断器、接触器、热继、中间/时间继电器、按钮、指示灯、灯泡、电机、端子排…）
2. 端子接线画布改造（走线/拐点/删除连线/撤销重做/锁定/网格/缩放自适应）
3. 仿真运行接线（复用引擎 + 动画状态）
4. 工作台四入口 + 我的作品（本地库）
5. 星三角/自锁/正反转三个示范作品的实物版数据

**二期 · 教学与社区闭环**
6. 练习模式（目标电路、实时校验、完成率、成绩）
7. 作品详情双视图 + 引用编辑/复制/发布
8. 首页 + 精选列表 + 收藏/关注（本地闭环）
9. 使用教程弹窗

**三期 · 内容与扩展**
10. 元器件百科（自动生成）、低压实操、考试电路包
11. 云端作品广场（cloud-service 可选）
12. 原理图视图自动布局

## 五、风险与对策

| 风险 | 对策 |
| --- | --- |
| 拟物 SVG 素材量大（60+ 种 × 状态帧） | 一期做「规范化拟物简化风格」统一绘制（栅格化母版+换色/换标牌），后续可替换精素材；元件外观与端子数据分离，可独立迭代 |
| 完全复刻社区功能需要后端 | 桌面/本地版先闭环（作品存本地资源库），云端共享列三期可选，避免阻塞 |
| 双视图同步维护成本 | 实物视图为主数据源；原理图模板先行，自动布局后置 |
| 仿真深度 vs 性能 | 保持拓扑逻辑仿真（与竞品同级表现：通断/吸合/延时/转向），不做数值级电路求解 |
